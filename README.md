
# 🧠 Brain Tumor Detection using Deep Learning (CNN + Transfer Learning)

This project implements a **Brain Tumor Detection system** using **Convolutional Neural Networks (CNNs)** and **Transfer Learning**.  
Given an MRI brain scan image, the model predicts whether the scan indicates a **tumor** or a **healthy brain**.

The project covers the **complete deep learning pipeline**:
- image data preparation
- preprocessing & augmentation
- CNN-based feature extraction
- binary classification
- performance evaluation
- deployment-ready inference logic

---

## 📌 Project Motivation

Manual analysis of brain MRI scans is:
- time-consuming
- expertise-dependent
- prone to inter-observer variation

This project demonstrates how **deep learning models** can assist medical professionals by learning **visual patterns** associated with tumors from MRI images.

⚠️ *This project is for educational and research purposes only and is **not a medical diagnostic tool***.
